# Inbox

Agents write proposals here. A person reads each one and either asks an agent
to apply it by name or deletes it. An agent deletes a proposal once it has
applied it, so this folder only holds open proposals.

- File name: `YYYY-MM-DD-topic.md`.
- Each proposal says what to change, gives the exact new text, and lists its
  sources. See [schema.md](../schema.md#proposals-inboxmd).
- Nothing in this folder is a fact until a person approves it and it is applied
  to `wiki/`.
